A minute-by-minute 4-hour forecaster for Polymarket's "Next CEO of NVIDIA?" prices, for the make.fun `polymarket-nvidia-ceo-forecast-01` bounty: per-market robust volatility from the last 12 hours of 1-minute moves, empirical jump-aware quantile tails that widen with sqrt(h), a small shrunk drift, and medians recentered so the markets' total probability mass stays at its checkpoint sum. Python 3.13 standard library only, deterministic, offline, no network.

## Run it

```sh
python3 score.py
```
